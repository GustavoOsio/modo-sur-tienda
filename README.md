# MODO SUR — Tienda juvenil

Tienda web demostrativa de ropa y calzado urbano, creada como trabajo escolar de Informática para estudiantes de bachillerato. La propuesta presenta una marca ficticia llamada **MODO SUR** con una identidad inspirada en la cultura urbana y el estilo personal.

## Ver el sitio

Abre `index.html` en un navegador moderno. El proyecto usa HTML, CSS y JavaScript sin pasos de instalación ni dependencias de compilación. La tipografía y las fotografías se cargan desde Google Fonts y Unsplash, por lo que esas imágenes necesitan conexión a Internet.

## Funcionalidades

- Catálogo de seis productos demostrativos con filtro por categoría y búsqueda.
- Bolsa de compra interactiva con cantidades, eliminación de productos y total en pesos colombianos.
- Persistencia del carrito en el almacenamiento local del navegador.
- Navegación móvil desplegable, mensajes de confirmación y formulario de novedades demostrativo.
- Entrada «Portada» con integrantes, institución, grado y espacios para docente y calificación.
- Diseño adaptable, enlaces de navegación, etiquetas semánticas y soporte para movimiento reducido.
- Metadatos para buscadores, Open Graph y marcado estructurado Schema.org para tienda.

## Estructura

- `index.html`: contenido, navegación y metadatos SEO.
- `styles.css`: identidad visual, diseño adaptable y animaciones.
- `cover.css`: presentación académica y sus ajustes para pantallas pequeñas.
- `script.js`: catálogo, filtros, búsqueda, bolsa y formulario.
- `PROYECTO.md`: contexto, objetivo, estrategia, alcance y próximos pasos.

## Alcance de la demostración

Los precios, productos, nombre comercial y promociones son ilustrativos. No hay inventario real, procesamiento de pagos, envíos, cuentas de usuario ni almacenamiento de correos. El formulario de novedades solo confirma la interacción en el navegador. Antes de publicar una tienda real se deben reemplazar estos datos, conectar servicios de comercio electrónico y configurar un dominio y datos sociales propios.
